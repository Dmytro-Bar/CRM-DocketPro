# DocketPro CRM

Веб-додаток для управління договорами, рахунками та актами DocketPro.  
Запускається локально на `localhost:8000`.

---

## Стек технологій

| Шар | Технологія |
|---|---|
| Backend | Python 3.9 + FastAPI |
| База даних | SQLite (`crm.db`) |
| Шаблони | Jinja2 |
| CSS / UI | Власна дизайн-система (styles.css + app.css) |
| Реактивність | HTMX (CDN) |
| Графіки | Chart.js (CDN) |
| Word-документи | python-docx |
| PDF-конвертація | LibreOffice headless |
| Excel-експорт | openpyxl |
| Банк API | Monobank API |
| Валютний курс | НБУ Open API (кеш у БД, оновлення раз на добу) |

## База даних

SQLite-файл `crm.db` у корені проєкту. Схема ініціалізується автоматично при запуску (`init_db()`).

| Таблиця | Опис |
|---|---|
| `clients` | Клієнти (ЄДРПОУ, назва, директор, адреса) |
| `contracts` | Договори (тип: Доступ / Погодинний, тариф, строк, прив'язка до курсу НБУ) |
| `invoices` | Рахунки (сума, статус, строк оплати, PDF-шлях) |
| `acts` | Акти виконаних робіт (статус, PDF-шлях) |
| `expenses` | Витрати (категорія, сума, валюта, курс конвертації) |
| `app_payments` | Оплати через додаток (LiqPay та ін.) |
| `expense_categories` | Довідник категорій витрат (редагується через UI) |
| `nbu_rate_cache` | Кеш курсу НБУ (fetched_ts, rate, rate_date) |

## Основні функції

### Дашборд
- KPI за обраний період: виставлено / сплачено / борг / витрати / ROI
- Графік помісячного доходу (Chart.js)
- **Блок курсу НБУ**: поточний курс USD/UAH (великий шрифт, дата оновлення)
- **Таблиця договорів з прив'язкою до курсу**: δ% від базового курсу, підсвічування алертів
- Таблиця всіх рахунків зі статусами (прострочені — вгорі)
- Список рахунків без актів, підписантів актів, договорів що закінчуються (≤60 днів)
- Фільтри за датою, клієнтом, типом договору

### Рахунки
- Форма виставлення з live-розрахунком суми
- Кнопки швидкого вибору періоду (1/2/3/6/12 місяців)
- Підтримка знижки та курсу валюти
- Автоматична генерація Word → конвертація в PDF
- Inline зміна статусу (Сплачено / Скасувати)
- Excel-експорт з фільтрами

### Акти
- Вибір рахунку без акту
- Генерація Word за шаблоном договору (стандартний або кастомний)
- Статуси: Чернетка → Направлений → Підписано
- Excel-експорт

### Договори / Клієнти
- Повний CRUD
- **Прив'язка до курсу НБУ**: фіксується базовий курс на дату укладення, поріг відхилення %
- Попередження про закінчення терміну дії
- Cascade-видалення (клієнт → договори → рахунки → акти)
- Excel-експорт, сортування колонок

### Банк / Платежі
- Завантаження CSV-виписки Приват24
- Підключення Monobank API (токен в `.env`)
- Автоматичне розпізнавання платежів за номером рахунку, назвою клієнта, ЄДРПОУ

### Витрати
- CRUD з формою додавання та inline-редагуванням
- **Категорії витрат** — керуються через UI (додавання / видалення)
- **Мультивалютність**: відображення оригінальної суми + курс + сума в гривнях
- Фільтри за датою та категорією, Excel-експорт

### Податки (`/taxes`) — новий розділ
- Звіт для ФОП 3 групи: єдиний податок 5% + військовий збір 1%
- Звітні періоди **наростаючим**: I квартал / Півріччя / 9 місяців / Рік
- Вкладки по роках (2024 / 2025 / 2026 / …)
- Джерело: оплачені рахунки + записи в Оплатах
- KPI-картки та розбивка по кварталах внизу

### НБУ API
- Автоматичне оновлення курсу USD/UAH раз на добу (фоновий asyncio-цикл)
- 6-годинний кеш у таблиці `nbu_rate_cache`
- Алерти на дашборді при перевищенні порогу відхилення по договорах

## Word-шаблони

Шаблони знаходяться в `_templates/`. Плейсхолдери у форматі `{{НАЗВА}}`.

**Рахунок:** `{{INVOICE_NO}}`, `{{CLIENT_NAME}}`, `{{CONTRACT_NO}}`, `{{PERIOD_FROM}}`, `{{PERIOD_TO}}`, `{{USERS}}`, `{{MONTHS}}`, `{{TARIFF}}`, `{{SUM}}`, `{{SUM_WORDS}}`, `{{DUE_DATE}}`

**Акт:** `{{ACT_NO}}`, `{{ACT_DATE}}`, `{{CLIENT_NAME}}`, `{{CLIENT_CODE}}`, `{{CLIENT_DIRECTOR}}`, `{{CONTRACT_NO}}`, `{{CONTRACT_DATE}}`, `{{PERIOD_FROM}}`, `{{PERIOD_TO}}`, `{{USERS}}`, `{{MONTHS}}`, `{{TARIFF}}`, `{{SUM}}`, `{{SUM_WORDS}}`
